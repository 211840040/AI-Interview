# 简历分析详情页 — 左侧 PDF 预览面板

日期：2026-06-04  
作者：Claude Code

---

## 一、目标

在简历分析详情页左侧（导航栏与内容区交界处）添加一个可展开/折叠的 PDF 预览面板。触发器按钮贴在导航栏右侧边缘，面板从导航栏右侧开始滑入覆盖内容区，不遮挡导航栏。

---

## 三、实现细节

### 触发器按钮
- `fixed left-64 top-1/2 z-50` — 贴在导航栏右侧边缘，垂直居中
- `w-8 h-16 rounded-r-md` — 细长竖条，右侧圆角
- `ChevronRight` 图标，展开时旋转 180°（变为向左指示「收起」）
- 仅当 `storageUrl` 存在且不在面试详情视图时显示

### 预览面板
- `fixed top-0 left-64 h-full w-[720px] z-30` — 从导航栏右侧开始覆盖
- 滑入动画：`initial={{ x: '-100%' }}` → `animate={{ x: 0 }}`
- 无遮罩层，不遮挡导航栏
- 面板头部：文件名 + 关闭按钮
- 预览区域：iframe 嵌入后端代理 URL `GET /api/resumes/{id}/file`
- 加载骨架屏 + 15 秒超时错误兜底 + 下载备选按钮

## 四、后端接口

`GET /api/resumes/{id}/file` — 后端通过 S3Client 代理下载简历原文件，返回 `Content-Disposition: inline` 以支持浏览器内联预览。
